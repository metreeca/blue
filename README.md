# @metreeca/blue

[![npm](https://img.shields.io/npm/v/@metreeca/blue)](https://www.npmjs.com/package/@metreeca/blue)

{TBD}

- shape-based validation framework for the idiomatic JSON-LD subset defined by @metreeca/qest
- based on SHACL
- "blue" as in "blueprints/models" for JSON-LD

# Installation

```shell
npm install @metreeca/blue
```

> [!WARNING]
>
> TypeScript consumers must use `"moduleResolution": "nodenext"/"node16"/"bundler"` in `tsconfig.json`.
> The legacy `"node"` resolver is not supported.
